§06kagenti · compute-agnostic protocoledge execution substrate · REV 2

Agents execute inside WebAssembly sandboxes orchestrated by Kagenti. SPIFFE SVIDs sign every tool call; local SQLite buffers hold state until bulk-synced to the ledger; physical-node-compromise triggers cryptographic shredding — the nonce zeroizes the buffer and the state becomes indistinguishable from noise.

Compute-agnostic execution substrate

Agents run the same code in Lambda@Edge, Cloudflare Workers, bare-metal Wasmtime, or on-device Wasm. The protocol abstracts the compute plane while preserving SVID signing and buffer zeroization guarantees.

WasmSPIFFESQLite bufferbulk-sync

Cryptographic shredding failover

On SVID revocation or tamper-detection, the local nonce zeroizes the buffer in one instruction. The buffer was encrypted with the nonce; without it, the ciphertext is noise. The node retains nothing useful.

kagenti.shred
on tamper_detect ∨ svid_revoked:
  zeroize(nonce)            // single-instruction, one-shot
  buffer := noise           // ciphertext without nonce is noise
  aperx.commit(e_shred, APX-HL-SHRED)
  // state is irrecoverable; principal must re-authenticate

Edge buffering & bulk-sync disconnected operation

Edge nodes may be disconnected for minutes to hours. Kagenti buffers tool-call traces locally in an encrypted SQLite store, signs each with the SVID, and bulk-syncs to the ledger when connectivity returns. Bulk commits preserve ordering via a hybrid logical clock.
