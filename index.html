The Epistemic Hyperledger: Optimistic Verification for ML Provenance

A directed-hypergraph substrate for verifiable provenance in applied intelligence

Abstract

We present AperX, an optimistic-verification ledger over a directed hypergraph whose vertices are ML artifacts (models, datasets, claims, execution traces) and whose hyperedges encode derivation, lineage, and tool-call sequences. Heavy hypergraph mathematics runs off-chain under a deterministic, content-addressed specification; the chain holds only commitments, bonds, and fraud-proof gates. A 72-hour challenge window permits any verifier to slash a false claim by producing a fraud proof. We show that possibility–necessity bands over the hyperedge space yield calibrated routing decisions, and that zero-knowledge execution proofs (ZKEP) over a Kagenti Wasm runtime allow agents to prove faithful execution without revealing weights, prompts, or internal state.

Executive Summary

Three load-bearing ideas drive the paper:

(1) Provenance is a graph property, not a document. A model weight is only as trustworthy as the derivation that produced it; a dataset is only as clean as the curation pipeline that prepared it; an agent's answer is only as honest as the trace of tool calls that generated it. We encode each as a vertex and every derivation as a directed hyperedge — an edge with an arbitrary set of sources and an arbitrary set of sinks.

(2) Verification is a game. We model the ledger as an optimistic game between a claimer (who stakes bond) and a pool of verifiers (who can slash false claims by producing a fraud proof). The 72h challenge window is the time horizon during which the verifier wins. We show that with a 1:10 bond-to-reward ratio, rational actors verify.

(3) Deception becomes arithmetic. An agent cannot forge a proof of honest execution, because the ZKEP proof is bound to the bit-level trace of the Kagenti Wasm runtime it ran in. Failed proofs are not opinions — they are fraud proofs, and they slash.

Key Theorems

Theorem 3.2 (Commitment soundness). For any hyperedge e committed to APX-HL, the probability that a 1-bounded adversary produces a valid fraud proof after the 72h window closes is bounded by 2−128, assuming SHA-256 and the discrete-log hardness assumption in the chosen curve group.
Theorem 4.7 (Possibility-band calibration). Let Π(t) and N(t) denote the possibility and necessity scores of task t against tier k. Then P(success | Π(t) ≥ τ, N(t) ≥ τ−ε) ≥ 1 − δ for empirically-measured δ < 0.002 on the MMLU and HumanEval benchmarks.
Theorem 5.4 (ZKEP completeness). For any execution trace τ produced by a conforming Kagenti Wasm sandbox, the ZKEP prover emits a proof π such that Verify(π, commit(τ)) = PASS with probability 1, and no proof π′ for any τ′ ≠ τ passes verification except with negligible probability.

Annex A — Deterministic Auditor Agents

Four auditor classes are defined: relational-calculus verifier, graph-theory clique detector, MMD/KL statistical watchdog, and egress-commit enforcer. Each carries an ACL that explicitly denies generative capability. We prove that a generative auditor can be corrupted by social-engineering the underlying LLM; a deterministic auditor can be defeated in exactly one way — by breaking the underlying mathematics, which is a loud failure visible across the whole platform.

Annex B — Kagenti Compute-Agnostic Protocol

We specify a Wasm-based sandbox that (a) instruments every tool call at bit level, (b) signs every state mutation with a SPIFFE SVID, (c) buffers state locally under a nonce that can be cryptographically shredded on network partition, and (d) emits ZKEP proofs compatible with the AperX verifier. Kagenti runs on any provider; the protocol is agnostic to underlying hardware, including evictable spot capacity.

Annex C — U-Statistic Novelty Under Domain Saturation

We define σd (domain saturation) and show that a two-sample U-statistic over embedding projections detects novel contributions even when the marginal output distribution is stationary. The gated annex is unlocked upon NDA execution.
